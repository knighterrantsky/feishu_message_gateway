# 验收清单

本次交付以实时转发约束验收：允许丢失和重复，客户端持久化，不进行数据库队列恢复、Webhook 签名或死信重放验收。

## 自动化验证

| 场景 | 验证内容 |
| --- | --- |
| 管理与客户端凭证 | 两类凭证不可互用；签发要求显式资源范围和有限 TTL |
| JWT 校验 | 错误签名、过期、错误签发者/受众、未来签发、其他算法被拒绝 |
| 授权 | 缺操作、跨会话发送、跨会话回复被拒绝；session_id 不提升权限 |
| 回复归属 | 向官方消息查询接口验证实际 chat_id；缓存结果也检查新凭证范围 |
| 订阅 | 省略过滤仍受 grant 约束；显式越权整体拒绝；同 ID 不同过滤条件冲突 |
| 分发 | 相同连接重叠订阅合并；不同连接广播；取消只影响自己的连接 |
| 连接生命周期 | 必须先鉴权；空闲到期也断开；断开清订阅；新连接不恢复订阅或历史 |
| 内存保护 | 单连接/全局字节上限、在途帧计数、慢连接隔离、数量上限 |
| 幂等 | HTTP/WS 合并重复请求，内容冲突；不同 principal/操作隔离 UUID |
| 重启语义 | 新命令服务生成相同上游 UUID，不伪装为恢复网关结果缓存 |
| 不确定结果 | 超时返回 outcome_unknown；只有显式重试才再次调用，UUID 不变 |
| 并发与取消 | 断开/取消不释放仍运行的 SDK 并发槽，不创建无界调用 |
| 接收与过滤 | 单聊/群聊、@ 本机器人、用户和群白名单、原始来源元数据 |
| 官方 SDK 契约 | 真实 dispatcher/WS ACK 编码；未有下游接收也可 ACK；发送/回复 request builder |
| 子进程通信 | 分片拼接顺序、断线尾帧丢弃、超限退出、监督重启不阻塞事件循环 |
| 客户端存储 | 示例客户端持久去重，重开数据库后保留去重记录 |
| 发布脚本 | 官方 GraphQL 参数、失败处理、完整 SHA、连续健康与版本验证 |

执行 `uv run pytest -q`。还需通过 lint、格式、类型检查和静态 OpenAPI 同步检查。CI 构建镜像后验证只读根文件系统、非 root、PORT、存活/未就绪和容器重启；假飞书配置不用于证明真实收发成功。
